SUNORA SOLAR WEBSITE — SETUP

Files:
- index.html: Website structure and content
- css/style.css: Light theme, responsive design and styling
- js/app.js: EMI calculator, package rendering, form and WhatsApp interactions
- data/data.js: Dummy business details, WhatsApp number, images, package prices and calculator assumptions

HOW TO RUN
1. Keep the folder structure unchanged.
2. Open index.html in a modern browser.
3. An internet connection is needed for the Google font and online Unsplash photos.

IMPORTANT CONFIGURATION
Open data/data.js and update:
- brand
- phoneDisplay and phoneLink
- whatsappNumber (digits only, include country code, e.g. 919876543210)
- email and serviceArea
- package prices and image URL if needed

WHATSAPP
The form creates a pre-filled WhatsApp message and opens wa.me. The visitor must press Send in WhatsApp. The static demo does not store submissions in a database or file.

DEMO/ESTIMATE NOTICE
Prices, interest rate, solar generation, savings and payback assumptions are illustrative only. Verify actual equipment, installation quotes, financing terms and current subsidy eligibility before publishing. Subsidies are not automatically calculated.
